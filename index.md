# Wolf Apps documentation

Guides, policies and support for each app.

## Apps

- [Cloud Connector for Jira](./jira-cloud-connector-docs/) — Sync issues, fields, statuses, comments and attachments between Jira Cloud sites, without sharing credentials.
- [Portal Fields for JSM Cloud](./jira-portal-fields-docs/) — Show customers the request fields they ask about, with charts and exports, on the Jira Service Management portal.

## Policies for all apps

- [Support SLA](./sla.html) — Support hours, response targets and security fixes.
- [Privacy policy](./privacy-policy.html) — What data each app handles, where it goes and how long it is kept.

End-user terms are set per app: [Cloud Connector for Jira](./jira-cloud-connector-docs/end-user-terms.html) · [Portal Fields for JSM Cloud](./jira-portal-fields-docs/end-user-terms.html).
