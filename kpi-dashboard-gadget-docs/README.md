# KPI Dashboard Gadget – documentation site

Source of the public documentation for **KPI Dashboard Gadget**, published with GitHub Pages at
<https://rsavaikar.github.io/documentation/kpi-dashboard-gadget-docs/>.

| Page | File |
| --- | --- |
| Home | `index.md` |
| Product guide | `product-guide.md` |
| Admin guide | `admin-guide.md` |
| For dashboard viewers | `for-viewers.md` |
| Troubleshooting | `troubleshooting.md` |
| Support | `support.md` |
| End-user terms | `end-user-terms.md` |

Each page is a Markdown file with a `layout: default` front matter. The site title, theme and plugins are shared by all apps and set in `_config.yml` at the repository root, because GitHub Pages reads it only there. Pushing to `main` republishes the site within a few minutes.

Images are in `assets/images/`. The logo comes from the app repository's `assets/marketplace/` folder; re-copy it there when it changes.

The Support SLA and privacy policy are shared by all apps: `sla.md` and `privacy-policy.md` at the repository root, with a section per app.
