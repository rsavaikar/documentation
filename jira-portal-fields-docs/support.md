# Support

*Last updated: 28 October 2026 · Rahul Savaikar*

Email [rahul.savaikar@gmail.com](mailto:rahul.savaikar@gmail.com). Support hours and response times are described in the [Support SLA](../sla.html). Many questions are answered in [Troubleshooting](./troubleshooting.html).

To help us help you quickly, include:

- your Jira site address (for example `yourcompany.atlassian.net`);
- the service project and, if relevant, the request keys involved;
- the exact message, including any **reference** it shows, or a screenshot;
- whether the problem is in the report, the charts or the settings, and for which kind of user (customer, agent or administrator);
- what you expected to happen and what happened instead.

Please don't send exports or screenshots that contain confidential request data.

**Security issues:** report them to the same address with "Security" in the subject.
